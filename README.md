# GTM Lab

I'm a product marketer with 7+ years in B2B SaaS, learning GTM engineering in public.

Every project here is open source. Each one runs on public data or on channels I own, teaches one skill, and ends with real numbers and a write-up. If you can't check the result, it doesn't count.

## Projects

| # | Project | What it does | Skill | Status |
|---|---|---|---|---|
| 01 | [Signal scanner](projects/01-signal-scanner/) | Watches a list of companies for signals (new roles, funding, launches) and turns each one into a CRM task | APIs, scheduling, CRM writes | Briefing |
| 02 | Content engine with evals | Drafts posts in my voice and scores every draft against a rubric | Structured outputs, evals, LLM-as-judge | Up next |
| 03 | Skool referral loop | Free resource → newsletter → Skool, tracked end to end | Funnels, attribution, lifecycle (B2C) | Planned |
| 04 | Outseta founder finder | New indie SaaS launches → enriched → scored → first-touch drafts I approve | Signals, enrichment, scoring (B2B) | Planned |

Projects 03 and 04 run GTM for products with affiliate programs. If I earn referral income from either, I'll say so in every post about it.

## How each project runs

1. **Brief.** The problem, who it's for, the metric, what I'll learn.
2. **Build.** I write the first version of the hard part myself. My AI coach (Claude) reviews it and explains.
3. **Ship.** Public code, a demo and real numbers.
4. **Review.** A senior-engineer-style review. I fix what it finds.
5. **Post.** A write-up on LinkedIn.
6. **Retro.** What I learned picks the next project.
